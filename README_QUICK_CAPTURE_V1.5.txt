QUICK CAPTURE V1.5（2026年10月18日）

変更内容
・タスク登録画面の「期日」の下に「次に触る日」を追加しました。
・日付欄を押すと端末標準のカレンダーから選択できます。
・任意項目のため、空欄でも登録できます。初期値は空欄です。
・入力した日付はTASK CONTROL Masterの「次に触る日」列へ保存します。
・連続登録時は次のタスクへ日付を引き継がず、空欄に戻します。
・Masterに該当列がない場合は保存エラーを表示します。TASK CONTROLでOneDrive同期後、未送信を再同期してください。

更新方法
既存のQUICK CAPTUREリポジトリへ、次の3ファイルを同じフォルダー位置に上書きしてコミットしてください。
  src/main.js
  src/workbook-append.js
  src/app-config.js

TASK CONTROLやDigital NOLTY、Entra設定の変更は不要です。
既存の認証、To Do・Outlook・Trello連携、メモ登録、依存関係の設定は維持しています。
NOLTYのDailyでは、設定した「次に触る日」の未完了タスクとして、一覧更新後に表示対象になります。

確認内容
・既存lockfileを使用したnpm ci --include=dev、npm run build成功。
・ブラウザーの模擬通信で日付指定／空欄登録、連続登録の初期化、To Do登録処理、スマートフォン幅を確認。
・実際にアップロードするExcelデータを読み戻し、「次に触る日」の保存と空欄保持を確認。
・実アカウントでの最終同期確認は公開後に実施してください。
